# Corpus d’inspiration de la niche

Les vidéos ajoutées par Marc sont dans `../downloads/`, classées par dossiers datés. `catalogue.json` permet de les retrouver depuis leur date, même sur un autre poste. Les originaux et miniatures sont sauvegardés dans la bibliothèque privée du studio ; les vidéos ne sont pas committées dans GitHub.

Lire [le mode d’emploi commun aux IA](../../../docs/REFERENCES.md). Pour lancer un épisode, indiquer **« Produis depuis le dossier AAAA-MM-JJ »**. Quand une date contient plusieurs vidéos, préciser l’identifiant ou utiliser la consigne proposée par le studio.

Le dossier `analyses/` contient les images, l’audio et les notes de travail préparés à la demande. Le catalogue n’affirme pas que toutes les vidéos ont déjà été analysées image par image. Chaque nouvel épisode doit conserver l’identifiant et l’empreinte de son inspiration dans sa provenance.
