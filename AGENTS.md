# Toon Studio

Lire `docs/PRODUCTION.md` et la charte du compte avant de produire. Pour Le Corps Parle.fr, vérifier `lcp-1.0.0` avec `python -m toonstudio.production style corps-humain`. Le casting, les fonds de série, la palette corail, les yeux, le filigrane, les badges et le format des sous-titres viennent du profil approuvé. Les changements de socle requièrent une validation et une nouvelle version.

Pour chaque nouvelle référence, consigner les actions, les intentions, les repères et les sources dans `provenance.md`. Le cadre mural secondaire porte un conseil court et propre au sujet. Livrer un export vérifié, le SRT et le ZIP de production. Écarter les références vidéo, les secrets, les caches et les pistes privées des commits.
